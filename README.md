## Automação

Este repositório possui **sincronização automática com upstream** via GitHub Actions:
- Executa diariamente às 2h UTC
- Cherry-picks inteligente de commits do [keiyoushi/extensions](https://github.com/keiyoushi/extensions)
- Substituição automática de APKs quando apropriado
- Criação de issues para conflitos que requerem revisão manual

📖 [Documentação completa do workflow](CHERRY_PICK_WORKFLOW.md)
